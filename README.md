# Editor Refrigeración

Prototipo de editor didáctico para crear animaciones simples de circuitos de refrigeración.

## Primera versión
- Carga de imágenes
- Posicionamiento manual
- Redimensionado
- Tuberías configurables
- Color y grosor
- Flujo animado y velocidad
- Reproducción/pausa

Proyecto independiente de enfri-ar-cursos.
